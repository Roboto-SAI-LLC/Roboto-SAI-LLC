# Licensing

Roboto SAI work is licensed in three tiers. Every tier leaves ownership with Roberto Villarreal Martinez; none of them
hands anyone ownership.

| Tier | Used for | File |
|---|---|---|
| **RVM License** (sovereign, the default) | Anything the Owner creates or owns that doesn't name another license. All rights reserved. | [`LICENSE`](LICENSE) |
| **PolyForm Noncommercial 1.0.0** | Public repos people may read and use, but not for commercial purposes without signed permission. | [`licenses/PolyForm-Noncommercial-1.0.0.md`](licenses/PolyForm-Noncommercial-1.0.0.md) |
| **Apache License 2.0** | Public repos released as open source. Credit required; no rights to the Roboto SAI name or marks. | [`licenses/Apache-2.0.txt`](licenses/Apache-2.0.txt) |
| **RVM Partner Agreement** (draft) | A signed, mutual agreement with a partner company for joint work. Not in force yet. | [`licenses/RVM-Partner-Agreement-DRAFT.md`](licenses/RVM-Partner-Agreement-DRAFT.md) |

## Which one applies

1. If a repository has its own `LICENSE` file, that file governs the repository.
2. If it has none, the RVM License applies to work the Owner created or owns.
3. Forks of other people's projects keep their upstream licenses. The RobotoSairif fonts are under the SIL Open Font
   License.
4. A written agreement signed by the Owner governs what it covers.

## Applying a public tier to a repository

- **PolyForm Noncommercial:** copy `licenses/PolyForm-Noncommercial-1.0.0.md` into the repository as `LICENSE.md`,
  keeping the `Required Notice:` line at the top.
- **Apache 2.0:** copy `licenses/Apache-2.0.txt` into the repository as `LICENSE`, and add a `NOTICE` file with
  `Copyright 2026 Roberto Villarreal Martinez`.
